⚠️ TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "Git is not recognized"
SOLUTION: Install Git from https://git-scm.com/downloads
         Restart PowerShell after installation

PROBLEM: "Authentication failed" or "Bad credentials"
SOLUTION: Create Personal Access Token:
         1. Go to: https://github.com/settings/tokens
         2. Click "Generate new token"
         3. Select "repo" scope
         4. Copy the token
         5. Use token as password when pushing

PROBLEM: "404 Page Not Found" after deployment
SOLUTION: Wait 2-5 minutes for GitHub to build your site
         Refresh browser after waiting

PROBLEM: Frames not showing on live site
SOLUTION: 
         1. Check if Frames/ folder was uploaded (view on GitHub.com)
         2. Open browser console (F12) and check for errors
         3. Verify frame naming: ezgif-frame-001.jpg, ezgif-frame-002.jpg, etc.

PROBLEM: "Repository already exists"
SOLUTION: Use different repository name OR run:
         git pull origin main --allow-unrelated-histories
         git push origin main

PROBLEM: "Large files detected" error
SOLUTION: Video file is excluded by .gitignore
         If you still get errors, run: git rm --cached *.mp4
